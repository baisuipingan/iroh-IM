# 比奇堡界面与传输修复上线

## 发布

- 前端：`https://im.pinkstar.cc`，Cloudflare Worker `iroh-chatroom`。
- Worker 版本：`02ed1f3a-a7ea-488f-9933-ec542656baf6`。
- 保留设计师新版界面，未重建 WASM 或 roomd，未清历史或身份数据。
- 服务端新增源 TCP 端口 15443 专用 BBR 策略服务，已启用开机运行。全局仍为 CUBIC，Docker 非默认路由保持原样。
- 端口策略、部署与回滚：`docs/relay-tcp-bbr.md`。

## 本轮修复

1. 顶栏提示音与设置页双向同步，快捷按钮不重建设置控件。
2. 拓扑订阅邻居上下线，及时更新 Gossip 数量。
3. 未连接不将候选中继冒充主链路；明确延迟为 HTTP 探测，不是文件数据 RTT。
4. 历史文本禁用入场变换，恢复翻页时阅读锚点稳定；保留实时消息动效。
5. 吞吐基准改为独立浏览器/身份/房间、真实 Worker OPFS，记录传输前日志和实际接收进度，交付及性能失败均返回非零。
6. 图片测试通过实际关闭移动端抽屉后操作；消息归属测试等待入场动画结束再测几何位置，不放宽方向或边界断言。
7. 文档移除“必须重启 roomd”和“浏览器走 UDP 7842”的错误前提。

## 验证

- 三端文件接收：26 项通过，含 2 MiB 失败续传与 8 MiB 取消后他人成功；没有放宽原 45 秒固定完成等待。
- Chrome/WebKit：图片布局 94 项、历史阅读锚点 20 项、消息归属 38 项、综合交互 52 项、主题同步 16 项、新增设置拓扑同步 4 项通过。
- 本地独立 OPFS：512 KiB 1.825 秒、2 MiB 2.441 秒、8 MiB 7.287 秒，逐字节校验成功。
- 线上独立 OPFS：512 KiB 1.217 秒、2 MiB 3.033 秒、8 MiB 9.409 秒，逐字节校验成功且发送端确认完成；默认性能门槛通过。
- 线上 Chrome/WebKit 设置与拓扑同步 4 项、真实三端文件接收/续传/拒绝/取消 26 项通过。
- 线上三人消息、人数、晚加入历史、跨页补齐与切房隔离 19 项通过。
- 生产 HTML、入口 JS、3 个 CSS、sidebar/motion/topology/notify 共 9 个资源与部署源 SHA-256 完全一致。
- 生产响应 HTTP 200，缓存 `max-age=0, must-revalidate`；中继 HTTP 健康、BBR 服务 active/enabled。

日志及逐样本记录：`output/playwright/handoff-review/`（忽略目录）。多传输并发时吞吐会下降，独立基准数值不是所有用户/出口/负载下的保证。
